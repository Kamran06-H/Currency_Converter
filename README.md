# Currency Converter

A web app that converts an amount from one currency to another using live exchange rates. Built with HTML, CSS, and JavaScript.

## Features
- Enter an amount and choose a source and target currency
- Flags update automatically when you change a currency
- Fetches current exchange rates from a free public currency API

## Files
- `index.html`: page structure
- `style.css`: layout and styling
- `code.js`: list of currency codes and their country codes (used for flags)
- `script.js`: fetches exchange rates and updates the result

## How to run
1. Download or clone this repository.
2. Open `index.html` in your browser.
3. Internet access is required to load exchange rates and flags.

## What I learned
Handling user input, calling an API with `fetch`, and updating the page with JavaScript.
